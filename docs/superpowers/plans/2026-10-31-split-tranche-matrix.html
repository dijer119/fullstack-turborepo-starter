분할매매 차수별 목록

첨부 이미지처럼 종목별 차수와 평가등락률을 비교한다. 기존 요약 보기·종목명순·검색·시장/상태 필터·무한 스크롤을 유지한다.

구현 순서와 검증

  1. 현재 보유 차수·재진입·부분 체결·미확정 주문을 표시하는 순수 요약 계산을 추가한다. 과거 매도 차수와 현재 보유가 섞이지 않는지 단위 테스트로 검증한다.
  2. 기본 차수 보기와 요약 보기 전환, 전체/보유/감시/주문 확인 필터, 고정 종목명 열과 가로 스크롤을 추가한다. 감시는 보유와 미해결 주문이 없는 실행 중 전략이다.
  3. 차수 칸은 전략 상세 링크로 연결한다. 매수 대기는 조건 감시 상태로서 주문이나 매수 추천을 뜻하지 않는다. 수익률은 최신 장부 가격 대비 현재 보유의 가중 매수가 기준이며 비용을 제외한 평가등락률로 명시한다.
  4. 타입·린트·관련 테스트와 실제 브라우저의 데스크톱·모바일, 다수 종목 스크롤을 검증한다. 실제 주문·전략 변경·DB 마이그레이션·자동 커밋은 수행하지 않는다.
