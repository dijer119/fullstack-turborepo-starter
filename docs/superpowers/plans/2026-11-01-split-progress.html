종목 상세 진행 현황

기본 진입을 진행 현황으로 변경하고 차수별 장부·최근 거래·설정 탭을 분리한다. 실거래·모의에 같은 요약 구조를 제공한다. 이미지의 설정 차수와 과거 거래 차수 불일치는 재현하지 않는다.

집계

매수 회차는 실제 매수 수량이 있는 slot·generation 장부 개수다. 반복 완료는 매수 수량이 있고 잔량이 0이며 해당 회차의 미해결 주문이 없는 경우다. 최근 주문 20건 제한과 무관하게 미해결 주문 수를 조회한다. 누적 실현손익은 손실·비용·부분 매도를 포함한 기존 장부 합계다. 막대는 매수 회차 중 청산 완료 회차의 비율로 표시한다.

진행 화면

  • 누적 실현손익, 총 반복 완료, 현재 보유 차수·수량 카드
  • 차수별 매수 회차·반복 완료·잔량·실현손익·미해결 주문
  • 최근 거래 5건 요약 및 전체 최근 거래 탭 이동
  • 실거래는 주문 시각과 누적 체결량·평균 체결가를 명시하고, 모의는 관측 번호를 사용한다.

구현·검증 순서

  1. 전체 회차 요약 함수를 테스트한다. 부분 매도·재진입·미체결·매수 0·종료 회차·손실을 포함한다.
  2. 조회와 공통 진행 컴포넌트·탭을 연결한다. 기존 설정 저장·시작/정지·복구를 유지하며 설정 초안은 탭 전환 뒤 보존한다.
  3. 타입·변경 파일 린트·관련 테스트, 실제 브라우저의 기본 탭·최근 거래·모바일·설정 초안 보존을 검증한다. 실제 주문·전략 저장·DB 스키마 변경은 실행하지 않는다. 이미 실행 중인 사용자 서버를 사용하고 별도 서버를 남기지 않는다.
