차수별 예산 방식 구현 계획

사용자가 두 방식의 추가를 요청함. 현재 작업 공간에서 executing-plans 흐름으로 직접 구현하고 독립 코드 검토를 받는다. 커밋하지 않는다.

승인된 검토안 · Next.js / TypeScript / Prisma SQLite / Vitest · 외부 의존성 추가 없음.

목표와 범위

신규 실거래 전략에 fixed/geometric/linear 방식과 배수(2차÷1차)를 저장하고, UI·생성 검증·워커의 계산을 일치시킨다. 최대 차수 기본 10. 기존 전략은 fixed/1, 모의 엔진의 고정 예산 동작 유지. 실제 주문으로 시험하지 않는다.

1. 공통 계산과 주문 규칙

src/lib/split/budget.ts에 getTrancheBudget(config, slot): number 및 getBudgetSchedule(config): {budgets:number[],total:number} 추가. base·차수·시장·모드·배수 검증, 2자리 배수, 기존 fixed 금액 정밀도 보존, 증가 예산은 원/센트 내림. 최대 금액 100억원·최대 50차. 소수 입력은 정수 스케일과 BigInt로 계산하여 내림 경계 오차를 방지.

먼저 budget.test.ts 및 live-rules.test.ts에 모드별 10차 합계(100만/1억230만/550만), 1.5배, 1배, KRW/USD 내림, 잘못된 값·합계 초과, 3차 재진입과 전량 익절 후 1차 초기화 테스트 작성 → 실패 확인 → 구현 → 통과 확인.

2. 저장과 호환성

SplitLiveStrategy에 budgetMode String default fixed, budgetMultiplier Float default 1 추가. 20261030020000_add_split_budget_modes 마이그레이션은 두 컬럼 추가만 수행. engine.validateConfig의 선택적 예산 설정 인수는 기본 고정 방식. createLiveStrategy와 listSplitLive에 필드 연결.

임시 SQLite에서 구 데이터 마이그레이션 보존·기본값, 생성 입력 검증, 두 방식의 3차 주문과 재시작 후 설정을 검증한다. 로컬 DB 일관된 백업 후 additive migration, 별도 Prisma generate. 기존 활성 전략·주문 식별자와 금액 보존 확인.

3. UI와 운영 반영

LiveManager에 방식 선택과 배수 입력, 전체 차수 표·합계·부족액·저장 차단, 목록과 시작 확인의 방식 표시. 기존 RateInput의 단위만 선택적 prop으로 확장해 %p 기본 동작을 유지하고 배수는 배 단위 사용. 배정 자금은 자동 증가시키지 않는다.

브라우저에서 10차 기본값, 배수 2의 두 모드, 부족 자금 저장 차단, 1.5배·미국 센트 표시 확인. 저장/시작 버튼으로 실거래 전략을 만들거나 시작하지 않는다. 전체 Vitest, TypeScript, 변경 파일 ESLint, diff 확인 후 단일 워커를 교체한다.

검토 초점

  • 생략된 필드는 구 버전 입력으로 호환하되 null/알 수 없는 모드는 거절.
  • 배수 1·고정 모드에서 기존 소수 넷째 자리 예산을 임의로 바꾸지 않음.
  • 큰 배수·50차에서 NaN/Infinity/저장 범위 초과 차단.
  • generation이 늘어도 slot별 예산 유지, 재시작 시 1차 배수 초기화.
  • 신규 설정 노출과 워커 교체 사이에 구 계산으로 주문이 나가지 않도록 반영 순서 관리.

실행 기록

공통 계산·주문 규칙·서버 저장의 실패 테스트를 확인한 뒤 구현했다. DB 복사본 마이그레이션은 기존 전략 4개·주문 4건의 모든 값을 보존했다. 로컬 DB 백업 후 additive migration과 Prisma generate를 적용했다. 앱·워커를 교체하고 기존 전략이 모두 fixed/1로 계속 감시되는 것을 확인했다.

독립 검토에서 발견한 숨겨진 배수 오류는 동일 금액 선택 시 1로 초기화하여 수정했다. 브라우저에서 누적 2배 총액 102,300,000원, 일정 증가 총액 5,500,000원, 부족액 표시·해제, 공란→동일 금액 복귀, 미국 1.15달러·1.1배의 1.15/1.26/1.39달러 및 합계 3.8달러를 확인했다. 테스트 목적의 실주문은 제출하지 않았다.
