관심종목 관리 확장

첨부 화면을 기준으로 기존 /stocks/watchlist를 확장한다. 최근 본 종목·전체 관심·미분류·사용자 그룹을 탭으로 제공한다. 그룹은 카테고리 분류 용도로 사용하며 하나의 종목을 여러 그룹에 담을 수 있다.

화면

연회색 배경(#f7f8fa), 흰색 목록, 남색 선택 탭(#22335e), 상승 빨강(#e54857), 하락 파랑(#3478f6)을 사용한다. 시스템 글꼴, 우측 정렬 가격, 데스크톱 두 열·모바일 한 열로 구성한다. 종목 아이콘은 이름 첫 글자이며 확인된 종목만 NXT 지원 배지를 표시한다. 가격 조회 시각을 표시하고 조회 실패는 —로 처리한다.

기능과 경계

종목 검색·추가·삭제, 그룹 생성·이름 변경·삭제, 종목의 그룹 등록·해제, 최근 본 30개 및 기록 비우기, 상세 화면 이동을 제공한다. 그룹 삭제는 관심종목을 삭제하지 않는다. 기존 구매가·주문 표는 표 보기로 유지한다. 기존 국내·미국 지원은 유지한다. 최근 본 기록은 클라이언트 상세 화면 진입 후 저장하여 prefetch를 제외한다. 실거래 기능·보유 전략은 수정하지 않는다.

구현 및 검증

  1. Prisma에 그룹·멤버십·최근 본 테이블을 추가한다. 기존 StockWatch 유지. 서비스와 DB 테스트로 중복·없는 종목·그룹 삭제 보존·최근 순서/상한을 검증한다.
  2. 기존 stock-watches 액션과 가격 조회를 재사용한다. 그룹·최근 조회를 결합하고 가격·시각·NXT 정보를 조회한다. 실패해도 저장 목록을 유지한다.
  3. WatchlistDashboard와 상세 기록 컴포넌트를 추가한다. 기존 메뉴와 표 관리 화면은 유지한다. 브라우저로 CRUD, 재조회, 탭·검색·모바일·공통 메뉴 진입을 검증한다.
  4. 타입·린트·관련 테스트를 통과한 뒤 DB 백업, migration, 웹 서버 반영을 확인한다. 자동 커밋하지 않는다.
