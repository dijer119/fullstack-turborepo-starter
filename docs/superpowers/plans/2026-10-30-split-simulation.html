차수별 장부·모의 실행 구현 계획

2026-10-30 · 사용자 승인 범위: 앞선 가능성 보고서의 모의 장부 단계. 기존 토스 조회를 재사용하며 실거래는 연결하지 않는다. 기존 company-map 패턴을 따라 현재 기능 브랜치에서 순차 구현한다. 커밋·운영 worker 재시작은 하지 않는다.

구현 완료 · 2026-10-30

분할매매 모의 장부 열기. 전종목 조회 화면에서도 진입할 수 있다. DB 백업 후 모의 전략·차수·실행 이력용 테이블 3개를 추가했다. 기존 실계좌 데이터와 운영 worker는 변경하지 않았다.

  1. 모의 전략 만들기에서 종목, 자금, 차수, 하락 간격, 익절률과 비용을 정한다.
  2. 직접 입력 전략은 시간 순서의 가격을 입력하고 가격 경로 반영을 누른다.
  3. 토스 시세 전략은 기존 토스 설정을 사용해 현재 시세로 모의 1회 실행한다.
  4. 차수 장부·실행 이력에서 청산·재진입 회차와 잔량·실현손익을 확인한다.

가격 원천은 생성 후 바꿀 수 없다. 입력 가격에서 전량 체결한다고 가정하며 토스 장부도 버튼을 누를 때만 진행한다. 토스는 최근 5분 이내 시세만 받아들인다. 수수료·세금은 사용자가 입력한 모의 비용이며 기본값은 0이다.

토스 조회기존 getPrices 어댑터를 모킹하여 검증. 실제 토스 API 호출과 실주문은 실행하지 않음.

예시 가격 10000 → 9000 → 8100 → 8910 → 8100을 모의 자금 300000, 차수당 100000, 최대 3차, 하락·익절 10%, 비용 0으로 실행하면 잔액 13520, 보유 33주, 실현손익 9720, 평가손익 -28900, 총자산 280820이 된다. 화면에 가격 경로 검증 예시 장부를 남겼다.

목표와 확정한 구현 규칙

  • 별도 화면에서 KRW/USD 전략을 만들고 정수주 차수 장부, 잔액, 실현·평가·총손익을 확인한다. 기본 수수료·세율은 0이며 사용자가 모의 비용을 지정한다.
  • 가격 경로 직접 입력과 토스 현재가 반영을 전략 생성 시 구분한다. 서로 다른 가격 원천은 한 장부에서 섞지 않는다. 시세 반영은 화면에서 명시적으로 실행하며 배경 worker는 변경하지 않는다.
  • 첫 가격에서 1차 진입. 후속 매수는 현재 보유한 직전 차수의 실제 매수가 대비 하락 간격을 사용한다. 한 가격 관측에는 추가 매수를 한 차수만 수행한다.
  • 매도는 차수별 매수가 대비 목표 가격 수익률로 판단한다. 이미 보유한 차수만 전량 모의 체결한다. 매도가 있는 관측에는 매수하지 않는다.
  • 청산된 하위 슬롯은 상위 슬롯이 보유 중이면 새 재진입 회차로 다시 살 수 있다. 모든 보유가 청산되면 종료하며 자동으로 1차를 재시작하지 않는다.
  • 모의 체결가는 관측 가격, 정수주 전량 체결이다. 거래량·호가·부분체결·실제 수수료를 재현하는 백테스트가 아님을 화면에 표시한다.
  • 예산은 매수비용까지 포함한다. 금액은 소수 넷째 자리로 반올림한다. 최초 예산은 차수별 배정 합계를 충족해야 한다.
