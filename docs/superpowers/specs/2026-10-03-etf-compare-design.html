ETF 수익률·분배 비교 화면 — 스펙 + 구현 계획

2026-10-03 · 앱: apps/company-map · 선행 작업: 스냅샷에 returns_json·dividend_json 저장(같은 날 구현, 미커밋)

1. 목적

관심 ETF 중 여러 개를 골라 분배금과 기간별 수익률을 한 표에서 비교한다. ETF 상세 화면은 한 번에 하나만 보여 주기 때문에, 고배당·커버드콜·액티브 ETF를 서로 견주려면 화면을 오가야 했다.

2. 확정된 결정 (사용자 답변)

항목결정
선택 대상등록된 관심 ETF(etf_watches) 중에서만 고른다. 미등록 ETF는 먼저 /stocks/etf에 등록한다.
화면 형태정렬 가능한 표 하나. 차트는 만들지 않는다.

3. 화면 동작

  • 경로: /stocks/etf/compare. 진입점은 /stocks/etf 상단의 "수익률·분배 비교" 버튼 하나다. AppMenu에는 추가하지 않는다.
  • 선택: 관심 ETF를 sortOrder 순서의 체크박스 칩으로 보여 준다. 선택 상태는 URL ?codes=A,B에 둔다. codes가 없으면 전부 선택된 상태다. 전체 선택·전체 해제 버튼을 둔다. 선택을 바꾸면 router.replace로 URL만 바꾸고, 서버는 다시 렌더링한다.
  • 표: 행 = 선택한 ETF, 열 순서 = ETF명(코드) · 분배율 · 분배금(TTM) · 올해 지급 횟수 · 1일 · 1주 · 1개월 · 3개월 · 6개월 · YTD · 1년 · 3년 · 5년 · 10년 · 기준일.
  • 시장가/NAV 토글: 수익률 열만 바뀐다. 기본값은 시장가다. 토글은 클라이언트 상태로만 두고 URL에 넣지 않는다.
  • 정렬: 열 제목을 클릭하면 내림차순, 다시 클릭하면 오름차순이다. 값이 없는 행은 방향과 관계없이 항상 맨 아래로 간다. ETF명 열은 가나다순이고 기준일 열은 정렬하지 않는다. 처음 정렬은 분배율 내림차순이다.
  • 최고값 강조: 숫자 열마다 최대값 셀을 굵게 표시한다. 동률이면 모두 굵게 하고, 값이 하나뿐인 열은 강조하지 않는다. 수익률 색은 상승 초록, 하락 빨강이다(/stocks/etf와 같다).
  • 표시 형식: 수익률은 +1.23%, 분배율은 4.77%, 분배금은 815원, 횟수는 9회로 쓴다. 분배금이 0이면 분배율·분배금·횟수 칸에 0을 그대로 보여 준다(정렬에도 0으로 참여한다).
  • 데이터 없음: 수익률·분배금이 한 번도 수집되지 않은 ETF는 행을 남기고 숫자 칸을 —로 둔다. 표 위에 "수익률·분배금 미수집: 코드…"를 안내한다.

4. 데이터 규칙

  • ETF마다 returns_json이 채워진 가장 최근 스냅샷과 dividend_json이 채워진 가장 최근 스냅샷을 따로 고른다. 최신 스냅샷만 보면 안 된다. 워커를 재시작하기 전까지 19시 자동 수집은 두 필드를 비워 둔 채 저장하므로, 그다음 날 표가 통째로 빈다.
  • 기준일 열에는 수익률 JSON의 referenceDate(Naver 기준일)를 쓰고, 없으면 그 스냅샷의 trdDd를 쓴다.
  • 스키마는 변경하지 않는다.

5. 구성 요소

파일역할
src/lib/etf/compare.ts (신규)순수 함수. buildCompareRows(inputs, basis)는 행을 조립하고 시장가/NAV를 고른다. sortCompareRows(rows, key, dir)는 null을 맨 뒤로 보낸다. maxByColumn(rows)는 열별 최대값을 구하고 값이 2개 미만이면 null을 돌려준다. 수익률 기간 코드 목록 COMPARE_PERIODS를 export한다.
src/lib/etf/compare.test.ts (신규)위 함수의 vitest.
src/actions/etf.tsgetEtfCompare(codes)를 추가한다. 관심 ETF 목록과 선택된 ETF별 입력(이름·수익률·분배금·기준일)을 반환한다. 코드는 기존 CODE_RE로 걸러 내고, 미등록 코드는 무시한다.
src/app/stocks/etf/compare/page.tsx (신규)서버 컴포넌트. searchParams.codes를 해석하고 action을 호출한다.
src/app/stocks/etf/compare/EtfCompareTable.tsx (신규)클라이언트 컴포넌트. 체크박스 칩, 시장가/NAV 토글, 정렬 상태, 표 렌더링을 맡는다.
src/app/stocks/etf/EtfManager.tsx"수익률·분배 비교" 버튼 하나를 추가한다.

6. 구현 순서

  1. compare.ts TDD: 먼저 테스트를 쓰고 실패(RED)를 확인한 뒤 구현해 통과(GREEN)시킨다. 테스트 항목은 행 조립(시장가/NAV 전환, 미수집 ETF), 정렬(내림차순/오름차순에서 null이 항상 뒤로 가는지, 이름 정렬), 최고값(동률, 값 1개면 null, 음수만 있는 열)이다. → 검증: vitest run src/lib/etf/compare.test.ts
  2. action getEtfCompare. → 검증: tsx로 한 번 호출해 18개 ETF가 반환되는지, 최근 스냅샷이 아닌 비어 있지 않은 스냅샷을 고르는지 확인한다.
  3. page + EtfCompareTable, 그리고 EtfManager 버튼. → 검증: 변경 파일 eslint, ETF 관련 파일 tsc 무오류.
  4. 전체 회귀: yarn workspace company-map test.
  5. 실제 화면: 브라우저 pane에서 /stocks/etf/compare를 연다. 체크 해제가 URL에 반영되는지, 정렬 클릭, NAV 전환, 최고값 굵게 표시를 확인한다. HMR로 반영되므로 dev 서버 재시작은 필요 없다.
